## pair_labels.csv

The manually labelled image pairs against which the deletion rule is calibrated.

| Column | Meaning |
|---|---|
| `image_a` | Image identifier, `ClassFolder/filename.jpg` |
| `image_b` | Image identifier of the other image in the pair |
| `target` | `1` if the two images are the same underlying photograph, `0` otherwise |

The two images may be listed in either order; notebook 01 matches pairs on an
order-independent key.

**Labelling protocol.** `1` means the same source photograph — including re-encoded,
rescaled, re-cropped or partially obscured variants. The same vehicle model, or even
the same vehicle in a different frame, is `0`. The distinction is *shared source
image*, not *shared subject*, because that is the property that makes an evaluation
optimistic.

Notebook 01 writes `pair_labels_template.csv` and matching contact sheets in
`figures/labelling/` on its first run. Complete the `target` column, save it as
`pair_labels.csv`, and re-run.
